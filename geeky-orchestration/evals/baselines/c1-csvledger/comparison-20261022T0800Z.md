### Task tier = Σ wᵢ · sᵢ = 72.6

How the inputs are taken, for all three runs:
- **V:** attempts per tool call that ran a block command, or a wider run such as the full suite, and produced a test outcome. Subset runs (`-k`), pytest exit 4, Bash exit 66 (D76) and D81/D84 faults are not attempts. Each main-thread code edit adds 1 attempt to the task that owns the file (D87).
- **R:** 1 when a phase reviewer's verdict names the task, else 0.
- **T:** `d` runs from the coder's dispatch (the `Agent` call's acknowledgement in `stream.jsonl`) to the later of the task's first passing validation run (the subagent's tool-result time in `stream.jsonl`) and its phase review's completion (the task-notification time in `session.jsonl`). `L_run` is `latency_median_ms` in `analysis.json`.
- **D:** 1 for every task.
- **LOC:** all lines (`git log --numstat`, added + deleted) under `csvledger/`, `tests/` and the root test config in the commits whose `Tasks:` line names the task. Tracking commits under `docs/` add none.
